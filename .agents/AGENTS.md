# Reglas de Trabajo del Proyecto

- **Análisis Obligatorio del Contexto**: Siempre que no conozcas o no tengas el contexto inicial de este proyecto, debes iniciar realizando una exploración y análisis preliminar del código fuente (estructura de carpetas, dependencias, frameworks, etc.) para comprender su propósito y funcionamiento general antes de realizar cambios o proponer soluciones.
- **Pausa ante Dudas**: Si en el proceso de análisis del proyecto o de un requerimiento surge alguna duda, debes pausar el análisis y preguntar directamente al usuario para resolverla antes de continuar.
